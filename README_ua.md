# Мапа повітряних тривог - адаптація для Lively Wallpaper

Кастомна адаптація даних та візуальних матеріалів із ресурсів **alerts.in.ua** та **neptun.in.ua**, створена спеціально для використання як інтерактивні вебшпалери у програмі **Lively Wallpaper**.

## 📌 Огляд

Цей проєкт надає зручний спосіб відображення актуальних даних та оновлень статусу в реальному часі прямо на вашому робочому столі. Він поєднує вебсервіси інформування із рушієм Lively Wallpaper, створюючи динамічне тло за допомогою стандартних вебтехнологій.

## 🛠️ Особливості

* **Працює на вебтехнологіях:** Створено повністю за допомогою HTML, CSS та JavaScript.
* **Оновлення в реальному часі:** Завантажує та інтегрує потоки даних безпосередньо у ваше робоче середовище.
* **Сумісність із Lively Wallpaper:** Повністю оптизовано для низького споживання ресурсів системи та плавної роботи всередині екосистеми Lively.
* **Чистий інтерфейс:** Візуальні елементи адаптовані спеціально для забезпечення гарної видимості ярликів та вікон на тлі робочого стола.

## 🧭 Встановлення та використання
1. Завантажте архів з цього репозиторію.
2. Відкрийте програму **[Lively Wallpaper](https://github.com/rocksdanister/lively/releases/tag/v2.2.1.0)**.
3. Перетягніть завантажений **архів (ZIP-файл)** безпосередньо у вікно Lively. Програма сама розпакує та налаштує все необхідне.

### 🐧 А як щодо Linux?

У зв’язку з тим, що у спільноти виникло чимало запитань щодо адаптації під Linux, у мене є чудова новина. Хлопець із [допису в Threads](https://www.threads.com/@p5ych0pat/post/DdUtDiUCCce) створив власну адаптацію версії Neptun під KDE, і це круто. 

На жаль, не маю можливості протестувати це власноруч, тому, якщо у вас є бажання, залишу посилання на його [репозиторій](https://github.com/p5ych0/plasma-air-raid-map)
